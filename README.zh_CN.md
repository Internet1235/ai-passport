# 元气随身听 · 联网版

可以听你说说今天的心情，用俏皮温暖的声音回应；也可以一键获得惊喜夸夸，或者听本地音乐放松。设备通过 Wi-Fi 直接连接千问，支持脱离电脑使用。

已发布的独立离线版保留在 `feature/energy-walkman`，此版本单独开发于 `feature/energy-walkman-online`。

- 主页：上下键选择，确定键进入。
- 对话页：按确定开始录音，再按确定发送；最长录音二十秒。回应过程中按确定可停止，上下键可翻阅回应文字。
- 本地播放页：上下键切歌，确定键播放或暂停。
- 长按上下键调节音量。长按确定返回主页；主页中长按确定可打开本地随身听。

字幕统一为 14 px。标题按整个屏幕居中，电量独立固定在右上角。内置十二首内容，断网后仍可播放。

打开**网络设置**，让设备创建临时热点。用手机连接后访问 `192.168.4.1`，从自动扫描的列表中选择附近的 2.4 GHz Wi-Fi，并填写密码；可点击“重新搜索”刷新列表，隐藏网络保留手动输入入口。首次使用需要填写自己的千问 API Key，模型服务可能产生费用。已通过 USB 设置默认千问密钥时，密钥框留空即可使用，填写新密钥可替换。配置仅保存到设备独立的 `wm_online` 命名空间；密钥不包含在源码和可分发固件中。只有主动开始录音时才开启麦克风，语音直接发送给千问服务。上下文仅在本次语音会话内保留，退出对话或闲置约 45 秒释放连接后会清除；本应用不会将录音或对话文案写入本地存储。

也可使用[私密 USB 配置工具](tools/configure_walkman_online.py)。设置、音乐导入和验证步骤见[指南](docs/walkman.zh_CN.md)。激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，构建并校验 `build/FoloToy-AI-Passport-full.bin`。编译、主机测试和设备测试应分别记录。
