# 星桥接线

旋转线路，把金色起点的能量送往每颗星。共 30 个确定生成且可解的关卡：
第 1–10 关为 3×3，第 11–30 关为 4×4，全程离线。
搭配轻柔原创八音盒循环音乐，以及选格、旋转、接通、提示、撤销、确认和通关音效。

| 按键 | 动作 |
| --- | --- |
| 短按上 / 下 | 逐行选择前 / 后一格，跨行循环 |
| 短按确定 | 顺时针旋转线路 |
| 长按上 | 接好第一处错误线路，本局使用提示最多一星 |
| 长按下 | 撤销上次旋转，内存中最多保留 128 次 |
| 长按确定 | 暂停：继续、重开、选关、说明、声音 |

金色边框为选中格，绿色为已通电，所有星点接通起点即可通关。
无提示且在目标步数内获得三星，超出步数但未用提示获得两星，使用提示获得一星。
最高星级不会下降。撤销不退还累计步数。目标步数为恢复生成树已知解的旋转次数，
不宣称是所有解法中的严格最优值。

旋转后静置一秒自动保存，暂停和通关立即保存。关闭电源前等待“保存中”消失。
失败会显示警告并重试。关卡、方向、步数、提示次数、星级和解锁进度跨重启保留；
仅移动光标不写闪存，撤销历史不跨重启保留。

## 声音

暂停菜单可切换 0%、25%、50%、75%（默认）、100% 五档音量，设置跨重启保留。
原创旋律以 96 BPM 循环 20 秒，搭配分解和弦与轻柔低音。进入菜单或播放音效时
背景乐自动减弱，音量采用渐变以减少突变声。固件通过六个整数振荡器，
按 256 个采样一块合成 16 kHz、16 位单声道 PCM。独立优先级 6 任务向官方
ES8311 BSP 送音频，LVGL 使用优先级 4。启用 I2S IRAM 安全中断以应对 NVS 写入。
USB 诊断使用 8 KB 发送缓存，每行截图之间让出执行时间；主机在读取超时后
保留尚未收全的一行，避免把传输片段误认为完整数据。
不使用第三方录音、网络音乐、麦克风采集或大型音频缓存。
旋律和合成源码位于 `main/starbridge_sound.c`。

用相同合成器生成试听文件：

```bash
python3 tools/render_starbridge_audio.py delivery/audio/preview.wav --effects
```

USB 状态报告初始化、写入错误、PCM 块数、最大送音间隔、合成耗时和音效计数。
这些诊断不能保证扬声器音色或没有可闻杂音，应在操作和保存进度时试听。

## 构建

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，输出为从零地址刷写的
`build/FoloToy-AI-Passport-full.bin`，目标 ESP32-C3、8 MB 闪存。
使用官方屏幕、按键和电量 BSP，LVGL 内存池为 48 KB，主任务栈为 8 KB。
修改文字后重新生成源于 OFL 文楷的 Starbridge 位图子集，
见[字体来源与命令](../assets/README.zh_CN.md#字库fonts)。
保留 12/16 像素字号，使用 4 位灰度抗锯齿。

保留官方默认 factory 分区。完整镜像会填充 NVS 间隙，开发时分段写入引导程序、
分区表和应用可保留 NVS。设备备份和身份资料不得进入公开固件。
程序只写 `starbridge` 命名空间，初始化失败不会清空 NVS。

## 验证

主机测试覆盖 30 关解法、旋转、循环选格、评分、提示、撤销边界、存档恢复，
并逐字节检验损坏存档。音频测试覆盖两分钟音乐与音效混合播放、幅度余量、
直流偏移、静音和分块一致性。USB 测试在真实固件上经过与实体按键相同的分发流程，
但不能单凭它确认实体按键手感、面板观感或续航。

串口 115200 波特率，发送单字符并换行：`?` 读取 JSON 状态，`u/d/o` 模拟
短按上/下/确定，`U/D/O` 模拟长按，`s` 保存，`c` 从实际 LVGL 刷屏流程
捕获 RGB565 图像，`m` 切换音量档位。`b` 持久保存测试前进度并开启新测试旅程，`e` 恢复进度，
支持重启后恢复。已有测试快照时拒绝覆盖，恢复失败则保留快照。
实体输入与模拟输入分别记录。图片是发送至面板的软件画面，不是实物照片。
自动化用法见 `tools/starbridge_device.py --help`。
